# Dark Matter Code for Zed

This directory contains the Zed port of **Dark Matter Code Black**, the true-black variant of the Dark Matter Code theme.

## Install locally

1. In Zed, run `zed: install dev extension`.
2. Select this `zed/` directory.
3. Open the theme selector and choose **Dark Matter Code Black**.

The theme follows Zed's `v0.2.0` theme schema. For publishing to the Zed Extensions Gallery, this directory can be submitted as its own extension repository or split into a dedicated repository.
